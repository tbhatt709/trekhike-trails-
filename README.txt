TREKHike Trails — FREE GITHUB PAGES PACKAGE

Files:
- index.html = website
- robots.txt = crawler instructions
- sitemap.xml = sitemap for search engines

FREE HOSTING:
1. Create/sign in to GitHub.
2. Create a PUBLIC repository named: trekhike-trails
3. Upload all 3 files to the repository root.
4. GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Your free address will be:
   https://YOUR-USERNAME.github.io/trekhike-trails/

IMPORTANT:
- Replace YOUR-USERNAME in robots.txt, sitemap.xml and the canonical URL in index.html with your GitHub username.
- Replace the sample phone/email/WhatsApp details in index.html with Tarun's real business details.
- The photos currently use remote Unsplash image URLs, so an internet connection is needed for those images.
